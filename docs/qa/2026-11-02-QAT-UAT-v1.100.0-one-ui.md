# QAT / UAT — v1.100.0 · One UI for every module

Date: 2 Nov 2026 · Scope: shared components, DT Refined component stylesheet, two colour schemes, security review, master plan.

## What changed
* `data-slot` (and `data-variant` / `data-size` where they apply) on button, input, textarea, select trigger, card (+header/title/description/content/footer), table (+header/body/row/head/cell), badge, tabs list/trigger, checkbox, dialog (overlay/content/header/footer), sheet, popover, select content, dropdown, tooltip, skeleton.
* Size tokens inside the primitives: `--btn-h-sm / --btn-h / --btn-h-lg`, `--field-h`, `--card-pad`, `--th-h`, `--td-py` (defaults equal the old sizes, so every other theme is unchanged).
* `src/styles/ui-refined-components.css` — DT Refined only, colour tokens only.
* Colour schemes Berry (`#be185d`) and Sunrise (`#d9480f`) added to Refined (nine in all).
* Docs: security review, master plan.

## Side effect to know about
`ui-modern.css` (v1.78.0) styles components through `[data-slot]`, but the primitives never emitted it, so those rules matched nothing. They now apply to every Modern-family theme (button weight, soft badges, table head, tab control, dialog shadows). Checked by screenshot on a Modern theme: no layout change, only the intended polish.
