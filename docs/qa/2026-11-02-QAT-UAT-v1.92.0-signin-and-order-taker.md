# QAT and UAT — DT POS Enterprise v1.92.0 (Owner sign-in, Order Taker inner screens)

Design package build order, **step 4**, last part. With this release every phone-app screen that can run on data the software already has is built.

## 1. What was built
### Owner app sign-in (OWN-01, OWN-02, OWN-03) — on the Owner app's route only
The Owner app opens at `#/owner-app` (the DT Owner Android app opens it). On that route, and **only** on that route:
- **OWN-01 Start screen:** full-bleed Digital Target purple with the mark and the crown badge, while the saved session is read.
- **OWN-02 Sign in:** a phone screen: purple header ("DT Owner — your restaurants, from anywhere"), the sign-in form's own card over it, dark when the owner chose dark. It frames both sign-ins an owner meets: the restaurant (cloud) login and the staff login that follows.
- **OWN-03 Waiting for device approval:** the owner's wording ("must be approved once from a device that is already signed in — More → Devices — or by Digital Target"), a **Check again** button that asks the server now, and "Sign in with another account".

How anyone signs in did not change. On every other route the sign-in is the frame of v1.71.0, with the till's wording. The device-approval wait now uses **one decision** for the live listener and for "Check again" (blocked → signed out; approved → carry on), so the two cannot drift apart.

### Order Taker (OTK-05, OTK-07, OTK-08, OTK-09)
- **OTK-08/09 Running bills — the order taker's own page.** The Bills tab used to be the cashier's page (with payment, void and reprint, none of which an order taker may do). It is now its own screen:
  - Search by table, order number or name.
  - Each bill shows its table, items, age, total and the kitchen's state: Not sent yet / Sent to kitchen / **Update not sent** / Cooking / Ready / Waiting for approval / On hold.
  - A bill opens in full: every line with a tick when the kitchen has it, a warning for lines not yet sent, the total, **Add items** (opens the bill in the POS, the same way as before) and **Call the cashier** (the restaurant's number from Settings; "No cashier number set" when there is none).
  - Payment, discounts and void are not offered. An order taker sees only their own bills, as before.
  - The cashier's Running Bills page is untouched.
- **OTK-07 Review and send.** When an order taker presses Send (either button), a sheet shows the table or order type, every line with − / + (a by-weight line shows its kg and is changed on the weight panel), the total, and **Send to kitchen** / **Back to the order**. What Send does is what it always did; this adds a look before it goes. A cashier never sees it, and a cashier's Running, Pay and Hold buttons are unchanged.
- **OTK-05 Item options.** The size / flavour / table / weight dialogs of the shared POS come up from the bottom as a sheet on a phone.

### Found while doing this, and fixed
- **Dialogs ignored the Order Taker's colours.** Dialogs and pop-ups are drawn outside the app's wrapper, so since v1.89.0 they came up in the till's colours, and dark mode did not reach them. The app's colour tokens (and the dark choice) are now also set on the page while the app is open, and removed when it closes.
- **A bill read "Sent to kitchen" after items were added to it.** It now reads "Update not sent". (Found in the browser check.)
- **The sheet first drew half off-screen.** The dialog centres itself with Tailwind 4's `translate` property, not `transform`; the first fix switched off the wrong one. (Found in the browser check.)

## 2. NOT changed, and why
- **Table choice and the cart itself** (the cashier's POS panel with its numpad) are the shared POS screen. Replacing them for the phone would replace the screen every waiter uses to create orders; it needs a trial on a real device first. The review sheet adds the design's "check once, then send" without touching that.
- **Needs new backend (step 6):** rider code sign-in (RID-03), an alert when a rider app is closed (RID-06), proof of delivery (RID-14), notifications (RID-20, OWN-18), opening hours and banners (OWN-20).
