## 2. Not executed / not done — said plainly
* **The Urdu was written by the assistant, not checked by a native-speaking proofreader.** Have someone who reads Urdu go through the three apps once; a wrong phrase is one line in `src/lib/phrasesUr.ts`.
* **Long explanations in the Owner app stay English** (about 100 of them); labels, statuses, buttons and empty states are translated. **Roman Urdu** for the apps is not done.
* A sentence that React draws in pieces ("… {name} … ") is translated piece by piece, so a few sentences read slightly stiffly.
* Some Android fonts draw Urdu in Naskh rather than Nastaliq.
* **No real phone was used.** Urdu and the right-to-left layout were checked in a desktop browser at phone size.
* **Account-only discount codes** (a code only a signed-in customer can use) need a new column in the database — not built; a code in an offer works for everyone who has it.
* The 38 desktop screens in the design's layouts, website pages WEB-02 and later, and the Rider's cash hand-over at day end (the server does not record how much the rider took) are not done.
