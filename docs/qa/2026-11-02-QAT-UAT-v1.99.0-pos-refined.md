# QAT and UAT — v1.99.0 (the POS in DT Refined — design package SW-03)

Owner's question after v1.98.1: "is this now exactly like the Refined design?" It was not (only emoji and text had been cleaned). This release builds the design's POS panel. **Under DT Refined only**; every other theme is exactly as before.

Side by side: the package's `design-project/02-restaurant-software/previews/sw-03.png` and the build `docs/audit/2026-11-02-pos-refined-v1.99.png` (the earlier build is `docs/audit/2026-11-02-pos-as-built-v1.93.png`).

## 1. What was built
- **Order header:** "Order #1043" with the status (New / Running / On hold / Part paid) and, under it, the table or the order type.
- **Order type** (Dining / Takeaway / Delivery) as one segmented control; **Add customer (phone or name)** as one row that opens the name and phone fields (or shows them when a customer is already entered).
- **Lines** as in the package: name, "Rs 650 each", a − / + stepper, the line total; no table header, no zebra; the delete icon is faint until the line is hovered or selected.
- **Totals** quiet, **Total** large.
- **Three actions and one big Pay:** Hold, Discount, Kitchen, then "Pay Rs …" (an order taker's is "Send to kitchen", to the review sheet as before). **Discount** opens the discount and promo-code controls (and a discount that is applied shows as a line even when they are closed).
- **One tap away:** Receipt, **Calculator** (the keypad, with CLR and Apply), **Cash received** (payment and change), **Note** (the kitchen special note, with a dot when there is one), **Token** (when the module is on). **Running / Credit / Void** stay at the bottom, quieter.
- **Item cards:** a gradient tile with one outline icon (instead of an emoji), larger corners, the price in the accent.
- Nothing was removed: every control exists and runs the same code (the Kitchen and Receipt actions are now named functions used by both the classic buttons and the new bar).

## 2. Found while doing this
- The first version let the opened panels push the bottom buttons off the screen; the middle section now scrolls and Hold / Discount / Kitchen / Pay and Running / Credit / Void stay in view (browser check).
- Line names were cut to "Chicken Tikka…"; the stepper and total were tightened and names now wrap.

## 3. NOT changed, and why
- **The amounts still read "PKR 2,900" (totals) and "Rs.1,450" (cards)**, the package shows "Rs 4,453" everywhere. The total follows the restaurant's currency (v1.69.0, with its own test); one consistent format is part of the component pass and needs a decision on the currency format for all screens.
- **The order type is in the cart header, not in the top row beside the search** as drawn. Moving it needs the left toolbar reworked.
- **Card grid density:** the package fills the row with four wide cards; the POS keeps its own card-size setting (Settings → screen layout).
- **The payment dialog (SW-04) and the weight panel (SW-05) keep their layout** — next.
- The mobile cart drawer, the classic and Espresso layouts are untouched.
