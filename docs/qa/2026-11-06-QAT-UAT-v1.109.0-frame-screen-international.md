## 2. The release guard
`npm run build` then `npm run smoke:worker` (the built worker must answer 200 on `/`) were run before this commit: **GET / → 200**, the intake endpoint answers JSON (not a crash page), an unknown path is 404.

## 3. Not executed / not done — said plainly
* **The 38 desktop screens in the design's own layouts (WP-4)** are not redesigned. What is done is cross-cutting: one title size, one gutter, overflow fixes, names on icon buttons. Pages still draw their own header; `PageHeader` is built and tested but not yet adopted by them.
* **The whole app is not translated.** The dictionary keys and the menu are; most page text is still English. Right-to-left is checked on the shell, the dashboard and the POS, not on every page.
* **Tax numbers are format-checked only.** No authority lookup. Rates are suggestions, never applied silently.
* **Erase on other devices:** the cloud copy of an order is overwritten by the normal sync; a day-close archive lives in each browser, so a second device keeps its own archive copy until that device runs the erase too.
* No real phone, GPS, iOS (there is no iOS project), real website posting to the endpoint, paper printing, or CAPTCHA was exercised here. APKs are debug-signed; a release build needs the four `ANDROID_*` secrets.
* The Windows shell (`dtpos-desktop`) is unchanged.
