# QAT and UAT — v1.97.0 (organisation structure: Owner → Branch Manager → Department heads → Floor staff)

## 1. What was built
- **Positions** (Users & Roles → edit a user → **Position**): Owner / Head Office, Branch Manager, six department heads (Kitchen, Store & Purchasing, Accounts, HR, Marketing & CRM, Delivery), and the floor roles. Picking one sets the role and every page and feature permission in one click; a head of department also clears the branch lock (all branches). Everything remains editable. The users list shows each person's position under their role.
- `docs/SYSTEM-STRUCTURE.md`: the structure, who manages what, where each thing lives (till, back office, head-office console, Owner app, phone apps, website), and what is not built yet.
- **No database change.** A department head is a `manager` with a curated page list, saved through the same path as before.

## 2. Found while building
An **empty feature list means "the role's defaults"** everywhere in the software, so a position meant to have no special rights, stored as an empty list, would silently receive a manager's void, refund, price-edit and complimentary rights. Positions with no features are therefore stored with an explicit marker (`feat.none`, which grants nothing). The same trap exists for any user saved with all feature boxes unticked in the existing page; it was not changed here.

## 3. NOT built (see section 4 of the structure document)
Regional/area managers, a department head limited to some branches, per-department dashboards, a sidebar re-labelled by department.
