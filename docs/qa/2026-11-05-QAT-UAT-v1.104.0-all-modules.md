# QAT / UAT — v1.104.0 · Every module in one look

## Survey method
A harness mounts any page of `src/pages` inside the real shell (DT Refined) on seeded data, 1440×900. Twenty-one module pages were captured and read: Tables, Menu Manager, Reports Center, Online Order Approval, Running Bills, Customers, HR, Accounts, Procurement, Promo Codes, Delivery Board, Analytics, Shift, Refund, Wastage, Recipes, Inventory, Users, Settings, Pickup, Kitchen.

## Found and fixed
| Found | Fix |
|---|---|
| Three amount formats on screen ("PKR 2,900", "Rs.1,450", "PKR 1450" with no grouping) | one formatter, PKR = "Rs 1,450"; 50+ hand-built strings moved onto it; 7 tests that pinned the old text updated |
| Reports Center: amount and date ran together ("Rs.2,75005/11/2026"); the tab bar's second row overlapped the table | plain tables get horizontal room; tab bar wraps inside itself |
| Pages started at different left edges (16 px vs 24 px) | one gutter for page wrappers that ask for padding; full-bleed screens untouched |
| Delivery board lanes in solid brown / blue / maroon blocks | quiet white heads, coloured edge from design tokens |
| Analytics charts in fixed blue / maroon / teal | accent first, then teal and orange |
| ~90 Roman-Urdu messages (hints, warnings, placeholders, a few customer-site toasts) | English |
| Order Taker app on the old small cards | photo-first cards, Add pill and category tiles in its teal; no-photo tile in the accent |

## Executed
`tsc` clean · full suite (see release notes) · screenshots `docs/audit/2026-11-05-*.png` (modules contact sheet, Order Taker, POS).

## Not executed / not done — said plainly
* **Owner app, Rider app and the customer website's inner pages were not restyled this round.** The Owner/Rider screens are their own components (not the POS grid), the website home was done in v1.98.0; both need their own pass.
* The website could not be screenshotted in the harness this round (it waits on a network probe); no website change was made.
* Printed receipt templates (about 60 hand-written "Rs. 1,234.00" layouts in `ReceiptPreview`) keep their own wording; they are the receipt designer's, and changing a printed slip is a separate, tested job.
* Roman-Urdu text that remains by design: the Urdu language dictionary (`i18n.ts`), the AI assistant's knowledge base, a few Super Admin internals. Some truncated strings in Super Admin were not converted.
* Windows shell: no change (it loads this web code, so it inherits all of the above).
* Phone and 4K widths of the desktop modules.
