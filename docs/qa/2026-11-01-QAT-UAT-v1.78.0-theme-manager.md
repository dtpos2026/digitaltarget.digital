## 2. Defects found while porting, and decisions
| # | Finding | Decision |
|---|---|---|
| TD-1 | The ported sidebar, launcher and Module Management called `visiblePagesForUser` without the restaurant's settings, so the Modern menu ignored the **plan** and the **optional-module switches** the Classic menu obeys. | **FIXED**, pinned by a test. |
| TD-2 | The sidebar swapped the restaurant's name for "VINCE BY TAIMOOR" on every premium theme (the v1.68.0 bug, re-imported with the port). | **FIXED** (`isVinceBrandActive`). |
| TD-3 | The Modern header squeezed the page title to "P…" and wrapped the clock because the cloud app has more live chips than the offline POS. | **FIXED** — chips scroll sideways, title and clock never shrink. |
| TD-4 | Closing the Windows POS left a process behind (hidden print window), so the shortcut did nothing the second time. | **FIXED** in the shell; **not verified on Windows**. |
| TD-5 | Modern POS order-screen layout (`data-pos-*` marks, Screen & Layout presets) is not in the cloud `POSScreen`. | **OPEN** — next piece of work. |
| TD-6 | The look is stored per device, not per restaurant. | **OPEN** — follow-up (store in restaurant settings). |
| TD-7 | "OK Art" theme: not found in the offline source. | **OPEN** — needs the owner's clarification. |

## 3. NOT EXECUTED
- A real Windows install, the UAC prompt, the shortcut click, an upgrade over an older build.
- Tablets, Firefox, Safari, the Windows shell's own window.
- Print output in Modern (the print window is built without the look attributes by design; a test pins that).
