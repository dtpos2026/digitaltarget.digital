## 2. Not executed / not done — said plainly

* **Not tried on a real phone.** The apps were tried in a browser at phone width and by tests. The test sheet is for that.
* **Signed release APKs were not made.** They need the owner’s own key and four GitHub secrets; nobody else should create it. See `docs/RELEASE-SIGNING.md`.
* **The Urdu and Roman Urdu have not been read by a native speaker.** The proofreading sheet (`docs/qa/urdu-proofread-sheet.html`) is how to do it in one sitting; the Roman form follows the Urdu automatically.
* **Desktop screens: 2 of 38 are in the master-detail layout** (Customers; Riders already was). The other 36 use the shared components and the DT Refined look but keep their older arrangement. They are listed in `docs/LAST-PHASE.md`.
* **The live website could not be reached from the build machine** (no route to the project from here), so the website was tried on the real page with the restaurant’s data seeded locally. The Offers page therefore showed its “could not load” banner next to the local deals — the live Offers feed was proved only inside the database.
* **Rider cash assumes the full amount due is taken at the door** (what the delivery function books). A part-payment taken by the rider is not separated.
* **The delivery-fee, minimum-order and radius settings are unset in every live restaurant today**, so no live order is priced with a fee yet; the code path is tested, not seen with real data.
* **Product details has no description or photo gallery** because the menu has no such fields; it uses what the menu has (picture, sizes, flavours).
* **The Customers panel on a wide window was checked by tests, not clicked in a browser** (the till needs a signed-in staff session, which the build machine does not have).
* The two database warnings about public functions (`anon_security_definer_function_executable`, `authenticated_…`) are the ordering website’s own endpoints, by design; leaked-password protection is a switch in the Supabase dashboard (Authentication → Policies) that only the owner can turn on.
